## Tables present in SFMC sheets but NOT needed by all flows

The SFMC_IIG.xlsx is a file-ingestion (ADLS→STG→STD) IIG. Other flow types omit certain sheets:
- **RDBMS ingestion** IIGs omit ADLS_DELTA_INGESTION_DETAILS and ALL_FILES_STATIC_INFORMATION
- **STD→Gold/EDH** IIGs use STGDELTA_GOLD_INGESTION_DETAILS instead of ADLS_DELTA/STGDELTA_STDDELTA

## Unique IDs in SFMC_IIG.xlsx

The reference IIG uses **synthetic placeholder IDs** (SYN-* prefix), confirming it was generated by the CodeGen agent:
- GROUP_IDs: SYN-GRP-001, SYN-GRP-002
- PIPELINE_IDs: SYN-PIPE-001 through SYN-PIPE-004
- CONNECTION_IDs: SYN-CONN-001 through SYN-CONN-004
- USER: SYN-RFC-001-syn-user-001

Real production IIG workbooks use numeric IDs (e.g., 21100002, 180276, 2109459812).
