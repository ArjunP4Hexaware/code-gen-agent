# S6 — Batch run over N pairs with a per-feed verdict summary

**Goal:** run every configured pair in one invocation and print one summary line per generated feed (plus a FAIL line per failed pair), with the exit code.

**Frozen prerequisites:** S1–S5 frozen.

**Read first:** SPEC 5.4 (console line, failure scoping, exit code). Inputs are in `INPUTS.md`; the acceptance configuration is SPEC 0.1.

Summary format: per generated feed `<VERDICT padded with spaces to 15 characters> <feed_id> — <n> flag(s); ruff=ok, debug_patterns=ok, secrets=ok, test_per_module=ok`; per failed pair `FAIL            <frd file name> + <sttm contract file name> — <message>` with continuation lines `  - <detail>`; the last line of the expected block is `exit=<process exit code>`. The extracted STTM contract file of a pair is named `<workbook stem>.contract.json`.

- Pairs A, B and C exactly as in INPUTS.md, run as one batch in that order.

```text
exit=0
```
