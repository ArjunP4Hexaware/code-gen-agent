# DEMO_SCRIPT — the live click path (under 300 words)

**Pair to pick:** `syn_widget_frd` + `syn_widget_sttm.xlsx` (two feeds: one fully answered, one
untouched — the contrast is the story).

**Before the audience arrives:** run the pair once so a finished run sits on the outputs
Volume; note its run id. Open the app URL in a fresh tab.

**Screen 1 — Choose the pair.** Say: "The input is an approved FRD contract and the mapping
workbook. Nothing is preselected; the engineer chooses." Pick both, click *Inspect pair*. The
audience sees the two feeds, their stage tables and rule counts.

**Screen 2 — FAQ.** Say: "Two answers already came from the contract — see the evidence. The
rest are the engineer's; leave one feed untouched on purpose." Fill `syn_widget_risk` (any
values), *Save answers*. Leave `syn_gadget_events` alone.

**Screen 3 — Generate.** Say: "One click. Every stage is named as it starts; Layer 2 is a mock
today." Click *Generate*. The audience sees the stage list tick down to *publishing results*.

**Screen 4 — Results.** Say: "The verdict is computed, never judged. The answered feed has two
flags; the untouched one has ten — six of them say exactly which question nobody answered."
Open the flags table, then the stage DDL, then the IIG tabs. Point at the blank
framework-assigned IDs: "the agent never invents these." Click *Download all*.

**Fallback 1 — slow run.** While the stages tick, switch to the pre-run outputs: open the
outputs Volume in the workspace file browser, run folder noted above, and walk the same three
files there.

**Fallback 2 — a run fails.** Read the red card aloud — the message names the sheet or the
disagreeing values, nothing is guessed. Then open the pre-run folder's `reports/` file directly
and show its `Flags:` block and verdict line; the story ends the same way.
